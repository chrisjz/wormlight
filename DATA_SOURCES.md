# Data sources

Every dataset Wormlight reads, what it's used for, and its licence.

> **Status: planned.** From milestone 0a this page is generated from `data/sources.json`, which pins each file by URL, commit or DOI, retrieval date and SHA-256, and CI fails if the two disagree. The same source list generates `public/data/NOTICE.md`, which ships with the site, so the data's licences and attributions travel with it (spec §9). Literature that supplies parameters rather than data is cited in `FIDELITY.md`.
